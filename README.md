# Digital Logic LED Control Circuit

## Overview
This project demonstrates a digital logic circuit built on a breadboard using NOT, AND, and NOR gates.

## Components
- Breadboard
- Logic gate ICs (NOT, AND, NOR)
- LEDs
- Switches
- Resistors
- Connecting wires
- Power supply

## How It Works
The circuit uses two switch inputs to control three LEDs:
- Input 1 ON: Blue LED
- Input 2 ON: Red LED
- Both inputs ON: Green LED

## Skills Demonstrated
- Digital Logic Design
- Breadboard Circuit Assembly
- Logic Gate Implementation
- Circuit Testing
