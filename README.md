# Digital Logic LED Control Circuit

## Project Overview
This project demonstrates the design and implementation of a digital logic circuit on a breadboard using NOT, AND, and NOR logic gates. Two input switches control three LEDs based on different input combinations.

## Components Used
- Breadboard
- NOT, AND, and NOR logic gate ICs
- Two input switches
- Three LEDs (blue, red, and green)
- Resistors and connecting wires
- Power supply

## Circuit Operation
The circuit produces different LED outputs depending on the states of the two input switches. When both switches are OFF, all LEDs remain OFF.

## Truth Table

| Switch 1 | Switch 2 | LED Output |
|----------|----------|------------|
|    0     |    0     |All LEDs OFF|
|    0     |    1     |  Red LED   |
|    1     |    0     |  Blue LED  |
|    1     |    1     |  Green LED |

**Note:** 0 = OFF, 1 = ON.
